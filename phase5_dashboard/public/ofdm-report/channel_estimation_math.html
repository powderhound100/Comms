A. Subcarrier Map

An OFDM symbol of N FFT bins is partitioned into guard bands (zeroed), a DC null, pilot subcarriers (known symbols), and data subcarriers (carrying information). The pilot spacing determines how well we can estimate the frequency-selective channel.

FFT = 64 — 52 used subcarriers, 13 pilots (every 4th)

FFT = 256 — 208 used subcarriers, 52 pilots (every 4th)

Why pilot spacing matters: With pilots every 4th subcarrier, the channel transfer function is sampled at the Nyquist rate for a channel impulse response of length L ≤ N/4. For FFT=64, this means L ≤ 16 taps can be perfectly reconstructed. For FFT=256, L ≤ 64 taps. The guard bands prevent spectral leakage into adjacent channels, and the DC null avoids DC offset from analog front-end impairments.

B. Least-Squares (LS) Estimation — Matrix Form

Signal Model at Pilot Subcarriers

At each pilot subcarrier index k ∈ {p0, p1, ..., pNp−1}, the received symbol is:

Y[k] = H[k] · X[k] + W[k] (B.1)

where Y[k] is the received frequency-domain sample, H[k] is the true channel frequency response, X[k] is the known pilot symbol (typically BPSK +1), and W[k] is additive white Gaussian noise.

Matrix Form

Stacking all Np pilot observations into vectors:

Yp = diag(Xp) · Hp + Wp (B.2)

where:

  • Yp ∈ ℂNp×1 — received symbols at pilot positions
  • Xp ∈ ℂNp×1 — known transmitted pilot symbols
  • diag(Xp) ∈ ℂNp×Np — diagonal matrix of pilot values
  • Hp ∈ ℂNp×1 — true channel at pilot frequencies
  • Wp ∈ ℂNp×1 — noise at pilot frequencies, Wk ~ CN(0, σ2)

LS Solution

The LS estimate simply divides each received pilot by the known transmitted pilot (element-wise):

ĤLS = diag(Xp)−1 · Yp = Yp ø Xp (B.3)

Since Xp[k] = +1 for BPSK pilots, this simplifies to:

ĤLS[k] = Y[k] / X[k] = Y[k] = H[k] + W[k] (B.4)

The LS estimate is unbiased but has variance equal to the noise variance at each pilot:

Var(ĤLS[k]) = σ2 / |X[k]|2 = σ2 (B.5)

Why LS Fails with Few Pilots

The interpolation problem: After obtaining ĤLS at the Np pilot positions, we need the channel estimate at all Nused subcarriers (including data positions). Simple linear interpolation between noisy pilot estimates propagates and amplifies noise.

Legacy System (4 pilots)

With only 4 pilots across 52 subcarriers, each pilot "covers" 13 subcarriers. The linear interpolation between pilots:

  • Cannot track rapid channel variations
  • Noise at one pilot corrupts 13 data estimates
  • Zero noise averaging — each pilot is used once
  • Pilot spacing >> coherence bandwidth for frequency-selective channels

BER = 0.19 (two-tap)

New System (13 pilots, FFT=64)

With 13 pilots every 4 subcarriers, combined with DFT-based LMMSE:

  • Nyquist sampling of channel in frequency domain
  • DFT-LMMSE regularization suppresses noise
  • All 13 pilots contribute to a joint time-domain estimate
  • Exploits channel sparsity (few taps in time domain)

BER = 0.0000 (two-tap)

C. Frequency ↔ Time Domain Relationship

The DFT Link

The channel frequency response H is the DFT of the channel impulse response h. If the channel has L taps (time-domain coefficients), this relationship is expressed as a matrix multiplication:

H = F · h (C.1)
(N×1) = (N×L) · (L×1)

where F is the partial DFT matrix with entries:

F[k, l] = exp(−j 2π k l / N)     k = 0, 1, ..., N−1    l = 0, 1, ..., L−1 (C.2)

At Pilot Subcarriers Only

We only observe the channel at pilot positions. Extracting the rows of F corresponding to pilot indices gives:

Hp = Fp · h (C.3)
(Np×1) = (Np×L) · (L×1)

where Fp selects only the rows of F at pilot subcarrier indices {p0, p1, ..., pNp−1}.

Matrix Dimensions for N=64, L=13

Key insight: With Np = 13 pilots and L = 13 channel taps, the system Hp = Fp h is exactly determined — Fp is a 13×13 square matrix. In the noiseless case, we can solve h = Fp−1 Hp exactly. With noise, we add Tikhonov regularization (Section D) to stabilize the inversion.

For N=256 with Np=52 pilots and L=52, the system is also exactly determined. If L < Np, the system is overdetermined and the regularized LS provides noise averaging.

D. DFT-Based LMMSE — Full Derivation

The DFT-based LMMSE estimator exploits the fact that the channel impulse response h has finite length L << N, making it sparse in the time domain. We estimate h from the LS pilot estimates, then reconstruct the full frequency response H at all subcarriers.

1 Obtain LS Estimates at Pilots

From Section B, we have the LS channel estimate at each pilot subcarrier:

ĤLS = Yp ø Xp = Hp + Wp ø Xp (D.1)

This gives us Np noisy samples of the true channel frequency response.

2 Form Partial DFT Matrix Fp

Construct the Np × L DFT matrix using only the pilot subcarrier indices:

[Fp]m,l = exp(−j 2π pm l / N)     m = 0, ..., Np−1    l = 0, ..., L−1 (D.2)

where pm is the absolute FFT bin index of the m-th pilot. Each row of Fp is a DFT basis vector evaluated at one pilot frequency, and each column corresponds to one channel tap delay.

3 Regularized Least Squares (Tikhonov)

We want to solve ĤLS = Fp h for h, but direct inversion amplifies noise. Instead, we solve the regularized problem:

ĥ = arg minh { ‖ĤLS − Fph‖2 + λ ‖h‖2 } (D.3)

Taking the derivative, setting to zero, and solving gives the closed-form solution:

ĥ = (FpH Fp + λI)−1 FpH ĤLS (D.4)
(L×1) = (L×L)−1 (L×Np) (Np×1)

where the superscript H denotes conjugate transpose (Hermitian).

4 Full Frequency Reconstruction

Once we have the time-domain estimate ĥ, we reconstruct the channel at all N subcarriers using the full DFT matrix:

Ĥ = Ffull · ĥ (D.5)
(N×1) = (N×L) · (L×1)

where Ffull has entries [Ffull]k,l = exp(−j 2π kl/N) for all k = 0, ..., N−1. This smoothly interpolates the channel estimate to data subcarriers without the noise amplification of simple LS interpolation.

Tikhonov Regularization — Geometric Interpretation

Understanding λ = σ2n · L

The regularization parameter λ controls the bias-variance tradeoff. The optimal value from MMSE theory is:

λ = σ2n · L = L / SNRlinear (D.6)

where σ2n is the noise variance per subcarrier. The factor L appears because FpH Fp has eigenvalues proportional to Np, so we need λ to be on the same scale as the noise energy projected into the time domain. Intuitively:

  • High SNR (σ2 small): λ → 0, solution approaches unregularized LS (trust the data)
  • Low SNR (σ2 large): λ → large, solution shrinks toward zero (trust the prior that h is small)
  • Each eigenvalue σi of FpHFp gets a shrinkage factor of σi / (σi + λ), damping directions with weak signal-to-noise

Complete DFT-LMMSE Pipeline (Expanded)

Given: received signal Y, known pilots Xp, pilot indices {pm}, noise variance σ2n, max delay L

1.   ĤLS[m] = Y[pm] / Xp[m]     m = 0, ..., Np−1    ← LS at pilots
2.   [Fp]m,l = exp(−j 2π pm l / N)    ← build partial DFT
3.   A = FpH Fp + σ2n L · IL    ← Gram + regularization (L×L)
4.   ĥ = A−1 FpH ĤLS    ← solve for CIR (L×1)
5.   [Ffull]k,l = exp(−j 2π kl / N)    ← full DFT (N×L)
6.   Ĥ = Ffull · ĥ    ← reconstruct at all N subcarriers

E. Zero-Forcing vs MMSE Equalization

After estimating the channel Ĥ, we must equalize — undo the channel distortion to recover the transmitted symbols. Two common approaches have dramatically different noise behavior.

Signal Model at Each Subcarrier

Y[k] = H[k] · X[k] + W[k] (E.1)

Zero-Forcing (ZF) Equalizer

X̂ZF[k] = Y[k] / Ĥ[k] (E.2)

Expanding with the signal model:

X̂ZF[k] = X[k] + W[k] / H[k] (E.3)

Effective noise after ZF:

σ2ZF[k] = σ2n / |H[k]|2 (E.4)
Problem: When |H[k]| → 0 (deep fade / null), the noise is amplified to infinity: σ2ZF → ∞. Even one subcarrier with a near-null channel response can destroy the entire codeword.

MMSE Equalizer

X̂MMSE[k] = Ĥ*[k] · Y[k] / (|Ĥ[k]|2 + σ2n) (E.5)

Expanding (where * denotes complex conjugate):

X̂MMSE[k] = G[k] · X[k] + G[k] · W[k] / H[k] (E.6)

Effective noise after MMSE:

σ2eff[k] = σ2n / (|H[k]|2 + σ2n) (E.7)
Bounded noise: As |H[k]| → 0, σ2eff → σ2n/σ2n = 1 (finite!). The MMSE equalizer "gives up" on deeply faded subcarriers rather than amplifying noise to infinity.

Noise Amplification Comparison

Why MMSE Matters for LDPC

LDPC decoders are iterative message-passing algorithms that rely on the statistical independence of errors across bits. When ZF equalization amplifies noise at faded subcarriers, it creates correlated burst errors — many bits from the same subcarrier are corrupted simultaneously. The LDPC decoder's belief propagation assumes independent noise and cannot handle these bursts efficiently. MMSE equalization keeps the noise bounded and approximately independent across subcarriers, allowing the LDPC decoder to converge reliably.

F. Per-Subcarrier Noise → LLR Soft Demapping

Effective Noise Variance per Subcarrier

After MMSE equalization, each subcarrier k has a different effective noise variance that depends on the channel gain at that frequency:

σ2eff[k] = σ2n / (|Ĥ[k]|2 + σ2n) (F.1)

This is the noise variance seen by the soft demapper after equalization. Subcarriers with strong channel response (|H| large) have small effective noise, while faded subcarriers (|H| small) have effective noise approaching 1.

Log-Likelihood Ratio (LLR) with Per-Subcarrier Noise

For a QPSK-modulated bit b carried on subcarrier k, the soft-output LLR is:

LLR(b) = log   P(b=0 | X̂[k]) / P(b=1 | X̂[k]) (F.2)

For QPSK with Gray mapping, the LLR for the real (I) bit simplifies to:

LLRI = 2 · Re(X̂[k]) / σ2eff[k] (F.3)

and for the quadrature (Q) bit:

LLRQ = 2 · Im(X̂[k]) / σ2eff[k] (F.4)

For Higher-Order QAM (16-QAM, 64-QAM)

The exact max-log LLR for bit bi of a QAM symbol on subcarrier k is:

LLR(bi) = (1 / σ2eff[k]) · ( mins ∈ Sbi=0 |X̂[k] − s|2 − mins ∈ Sbi=1 |X̂[k] − s|2 ) (F.5)

where Sbi=0 and Sbi=1 are the subsets of the QAM constellation where the i-th bit is 0 or 1, respectively.

Why Per-Subcarrier Noise Matters for LDPC

Truthful confidence per bit: The key insight is that σ2eff[k] appears in the denominator of every LLR formula. This means:
  • Strong channel (large |H|): small σ2eff → large |LLR| → decoder is told "this bit is very reliable"
  • Weak channel (small |H|): large σ2eff → small |LLR| → decoder is told "this bit is unreliable, don't trust it"

Without per-subcarrier noise (using a flat σ2 for all subcarriers), the LDPC decoder would over-trust bits from faded subcarriers, leading to decoder failure. With truthful per-subcarrier LLRs, the decoder can use its redundancy to correct the unreliable bits by relying on the reliable ones.

Rayleigh vs Rician Fading

Rayleigh Fading

Used by: TU-6, COST207-HT, Brazil-D

hl ~ CN(0, Pl)

No line-of-sight (LOS) component. The tap gain has zero mean, and its envelope follows a Rayleigh distribution. Deep fades (|hl| → 0) occur with significant probability, making this the most challenging fading model. The channel frequency response can have deep nulls at certain frequencies.

PDF of envelope: f(|h|) = (2|h|/σ2) exp(−|h|2/σ2)

Rician Fading

Used by: Brazil-A (LOS path)

hl ~ CN(μl, Pl)

Has a dominant line-of-sight (LOS) component (μ ≠ 0) plus scattered multipath. The K-factor = |μ|2/P measures LOS strength relative to scatter. Higher K means less severe fading — the channel never fades below the LOS level. When K=0, Rician reduces to Rayleigh.

PDF of envelope: f(|h|) = (2|h|/σ2) exp(−(|h|2+|μ|2)/σ2) · I0(2|h||μ|/σ2)

Brazil DTV Channel Profiles

The Brazilian DTV channel models (defined by SET/ABERT) characterize reception conditions specific to Brazilian geography and urban environments:

  • Brazil-A: Rooftop reception with clear line-of-sight. Rician fading with strong K-factor. Represents the best-case scenario in Brazilian broadcasting. Short delay spread (~3 samples).
  • Brazil-D: Indoor portable reception in dense urban areas. Pure Rayleigh fading with severe multipath. Large delay spread (~25 samples). Similar in difficulty to TU-6 and represents worst-case Brazilian reception.

These profiles are used in ISDB-Tb (Brazilian digital TV standard) conformance testing and are relevant to ATSC 3.0 since both operate in similar UHF frequency bands in urban environments.

TU-6 Delay Spread vs Cyclic Prefix

Key insight — why TU-6 shows residual ISI at FFT=64:

The TU-6 channel has a maximum delay spread of approximately 30 samples. The cyclic prefix (CP) for each FFT size is N/4:

FFT SizeCP LengthTU-6 DelayCP ≥ Delay?
64 16 ~30 NO — ISI!
256 64 ~30 YES
8192 2048 ~30 YES (massive margin)

When the CP is shorter than the channel delay spread, multipath components from the previous OFDM symbol leak into the current symbol, causing inter-symbol interference (ISI) that cannot be removed by any equalization technique. This is a fundamental OFDM limitation, not an estimator failure. Increasing FFT size (and thus CP) fully absorbs the delay spread.
